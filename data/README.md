# IP-SAKTI Knowledge Base

Store curated, versioned source documents here during development.

Recommended categories:
- Indian IP statutes and rules
- Ayurveda / AYUSH regulations
- International IP treaties and frameworks
- Pharmacopoeial standards
- Registry and prior-art records
- Relevant case-law documents

For production RAG, keep metadata such as:
- source title
- issuing authority
- jurisdiction
- document type
- publication/effective date
- version
- URL
- page/section
- retrieval timestamp

Do not treat this folder as legal advice or as a substitute for source validation.
